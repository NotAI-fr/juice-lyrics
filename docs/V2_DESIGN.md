# Historical v2 design

application with Dashboard, Browse, Library, Downloads, Settings, global Help,
MP3/FLAC/M4A support, and a compatibility CLI.

This filename remains for historical links, but its prospective naming and
screen proposals are no longer authoritative. See:

- `PROJECT_STATE.md` for the implemented checkpoint and remaining roadmap;
- `UI_DESIGN.md` for current interaction rules;
- `USER_FLOWS.md` for current workflows;
- `ARCHITECTURE.md` and `DECISIONS.md` for technical constraints.
