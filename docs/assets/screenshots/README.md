# Screenshot plan

Store public README screenshots in this directory as PNG files. Do not commit
captures containing a username, absolute home path, terminal title with host
information, tokens, private state, download URLs, or a real personal library
listing.

The current `dashboard-synthetic.png` is an application-rendered demonstration
using synthetic data. The following manually captured images are still wanted:

1. `dashboard.png` — Dashboard at approximately 120×36 cells, with a generic
   library path and synthetic counts.
2. `browse-search.png` — Browse search results, pagination, and the details
   panel using public catalogue data.
3. `library-health.png` — Library showing healthy, follow-up (`~`), Unknown,
   and genuine-error (`!`) distinctions using disposable media.
4. `issues.png` — Issues reasons and safe actions using disposable media and
   synthetic paths.
5. `downloads-queue.png` — A non-active disposable queue with no signed or
   private download URL visible.
6. `metadata-repair-preview.png` — A preview before confirmation, using a
   disposable file and generic metadata.

Use a consistent terminal theme and crop away unrelated desktop content. Check
each image visually and search its metadata before linking it from the main
README. Do not add empty placeholders or broken image links.
